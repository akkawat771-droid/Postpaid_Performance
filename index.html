8ข้อมูลเชิงลึกสำหรับผู้บริหาร (สร้างอัตโนมัติ)
• %ACH / % RR ACH คำนวณจาก ACTUAL-RR ÷ TARGET ของแต่ละแถวข้อมูล (ตรงกับค่าที่ปรากฏใน Source file คอลัมน์ %ACH)
• Bucket แบ่งตาม %ACH: Exceeds Target ≥120%, On Target 100–119%, Near Target 70–<100%, Below Target >0–<70%, No Sales = ACTUAL-RR เท่ากับ 0 (พนักงานที่ไม่มี Target จะไม่ถูกนับใน Bucket)
• No Sales Analysis นับเฉพาะพนักงานที่มี Target > 0 · Heatmap "AVG Productivity" ใช้ค่าเฉลี่ยต่อพนักงาน 1 คนในแต่ละกลุ่ม — สีเข้ม = ค่าเฉลี่ยสูง
• ข้อมูลเฉพาะแถวที่คอลัมน์ "QTY | REV" = REV และ PRODUCT = POSTPAID จาก Sheet "INDY-(REV-QTY-POST)" · Data as of อ้างอิงจาก Sheet "AS_OF"
• Retail WW Performance: %ACH NET AMOUNT คำนวณจาก RR NET AMOUNT ÷ TG NET AMOUNT ของแต่ละร้านค้า (ระดับร้านค้า ไม่ใช่ระดับพนักงาน) · Bucket: No Sales = NET AMOUNT เท่ากับ 0, Needs Improvement <50%, Getting There 50–<80%, Almost Target 80–<100%, Target Achieved ≥100% · %MOM NET AMOUNT คำนวณจากคอลัมน์ "MOM Net Amount" ในไฟล์ Sale_Postpaid.xlsx
